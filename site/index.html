100 apps. Which ones can be agent toolkits today?

An agent researched all 100 — auth scheme, whether an outside developer can actually get a credential, API surface, existing MCP, and a buildability verdict with evidence. Then it was graded: against 100 labels a human wrote by hand, and against Composio's own production catalog. The findings, the agent, and the proof it is trustworthy are all on this page.

Verification

How I know the findings are trustworthy — and where they are not

Three separate measurements, deliberately not averaged. A 20-app gold set hand-labelled from primary sources before any grading code existed; an independent cross-check against Composio's shipped auth config on every app it already covers; and a real browser sent to the pricing pages for the one field documentation never states.
